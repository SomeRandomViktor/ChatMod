### 🇧🇷 Português

### O que é o ChatMod?

O ChatMod é um projeto criado para reunir, organizar, desenvolver e compartilhar Mods e Scripts destinados ao ChatGPT. Seu principal objetivo é permitir que os usuários personalizem suas experiências de utilização da inteligência artificial por meio de instruções, interfaces interativas, ferramentas e comportamentos personalizados.

O ChatMod funcionará como um banco comunitário de Scripts, onde qualquer pessoa poderá encontrar criações de outros usuários, experimentar novas funcionalidades, compartilhar suas próprias ideias e contribuir para o crescimento da biblioteca.

### Como funciona?

A biblioteca será hospedada em um repositório público no GitHub, organizado em categorias e contendo arquivos que representam os diferentes Mods disponíveis.

Os usuários poderão utilizar dois formatos principais de criação:

* mGPT Mods (.mod): arquivos desenvolvidos utilizando a mGPT (Mods for ChatGPT), uma linguagem criada para simplificar a construção de interfaces e experiências interativas por meio de comandos próprios e instruções em linguagem natural.

* Prompt Scripts (.prompt): Scripts criados exclusivamente com descrições e instruções em linguagem natural, sem exigir conhecimentos de programação.

Os usuários também poderão desenvolver seus próprios Scripts utilizando o Script Generator, uma ferramenta planejada para facilitar a criação de Mods. Ela ajudará a estruturar as ideias do usuário, gerar os arquivos correspondentes e fornecer instruções para publicação na comunidade.

### Uma comunidade aberta

O ChatMod não será apenas um repositório de arquivos. A proposta é construir uma comunidade colaborativa na qual os usuários possam criar, compartilhar, testar, corrigir e melhorar os Mods existentes.

Qualquer pessoa poderá propor novos arquivos ou melhorias. As contribuições serão avaliadas antes de serem adicionadas à biblioteca oficial, garantindo melhor organização, qualidade e compatibilidade.

Os Scripts criados individualmente não serão publicados automaticamente. Cada criador terá liberdade para manter suas próprias criações privadas ou submetê-las voluntariamente à comunidade.

### Nosso objetivo

O objetivo do ChatMod é tornar a personalização do ChatGPT mais acessível, organizada e criativa. Queremos permitir que pessoas com diferentes níveis de conhecimento possam desenvolver suas próprias experiências, desde simples personalizações feitas com texto até interfaces mais elaboradas utilizando a linguagem mGPT.

O projeto busca transformar a criação e o compartilhamento de personalizações em uma experiência comunitária, na qual qualquer pessoa possa contribuir com novas ideias e funcionalidades.

### 🇺🇸 English

### What is ChatMod?

ChatMod is a project designed to collect, organize, develop, and share Mods and Scripts for ChatGPT. Its main purpose is to allow users to customize their artificial intelligence experience through instructions, interactive interfaces, tools, and personalized behaviors.

ChatMod will work as a community-driven Script library, where anyone can discover creations made by other users, experiment with new features, share their own ideas, and contribute to the continuous growth of the platform.

### How does it work?

The library will be hosted in a public GitHub repository, organized into categories and containing files representing the different available Mods.

Users will be able to create Mods using two main formats:

* mGPT Mods (.mod): files developed using mGPT (Mods for ChatGPT), a language designed to simplify the creation of interfaces and interactive experiences through custom commands and natural-language instructions.

* Prompt Scripts (.prompt): Scripts created entirely through natural-language descriptions and instructions, without requiring programming knowledge.

Users will also be able to create their own Scripts using the Script Generator, a planned tool designed to simplify the Mod creation process. It will help structure user ideas, generate the corresponding files, and provide instructions for publishing contributions to the community.

### An open community

ChatMod is not intended to be just a file repository. Its vision is to build a collaborative community where users can create, share, test, fix, and improve existing Mods.

Anyone will be able to propose new files or improvements. Contributions will be reviewed before being added to the official library, helping maintain organization, quality, and compatibility.

Individually created Scripts will not be published automatically. Every creator will be free to keep their creations private or voluntarily submit them to the community.

### Our goal

ChatMod aims to make ChatGPT customization more accessible, organized, and creative. We want people with different levels of technical knowledge to develop their own experiences, from simple text-based customizations to more advanced interfaces built with the mGPT language.

The project aims to transform customization and Script sharing into a collaborative experience where everyone can contribute new ideas and features.
